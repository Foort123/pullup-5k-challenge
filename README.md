# Челлендж 5 000 подтягиваний (30 дней)

Интерактивное веб-приложение для прохождения 30-дневного челленджа на **5 000 подтягиваний**.
Создано для тренировок на ПК и смартфонах с поддержкой облачной синхронизации прогресса.

---

## Возможности

1. **План челленджа на 5 000 повторов**:
   - 30 дней сбалансированных нагрузок.
   - Сумма целей строго равна **5 000**.

2. **17 уровней статусов с цветовой градацией**:
   - **1–4**: 🟢 Зелёный (Начальные: Начинающий, Новичок, Любитель, Практик)
   - **5–8**: 🟡 Жёлтый (Прогресс: Энтузиаст, Атлет, Крепыш, Турникмен)
   - **9–13**: 🟠 Оранжевый (Мастерство: Экватор силы, Штурмовик, Стальной хват, Мастер перекладины, Гладиатор)
   - **14–17**: 🔴 Красный (Элита: Титан, Железный монстр, Властелин гравитации, Легенда 5 000)
   - Круглые бейджи с номерами уровней и интерактивное модальное окно всех статусов.

3. **Синхронизация между устройствами**:
   - Авторизация по логину и паролю.
   - Облачное сохранение в реальном времени (Firebase Realtime Database) для непрерывной синхронизации между ПК и телефоном.
   - Поддержка экспорта и импорта `progress.json`.

4. **Умный алгоритм переноса недобора**:
   - При нехватке времени или сил недобор автоматически равномерно распределяется по оставшимся незавершённым дням.
   - Итоговая сумма 5 000 сохраняется при любых переносах.
   - Возможность переноса и сброса для любого конкретного дня.

5. **Дизайн в стиле Apple**:
   - Палитра **Dark Monochrome + Warm Ivory**.
   - Эстетика матового стекла (**Glassmorphism**).
   - Адаптивность для мобильных экранов и десктопа.
